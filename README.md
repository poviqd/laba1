# 👉Clash of Clicks👈

Простая игра для двух игроков: нажимайте на свою кнопку и постарайтесь сделать 100 кликов быстрее, чем соперник.

## ✨Особенности
Полностью автоматическое соединение(возможны проблемы из-за firewall и ограничений провайдера).

## ❔Как играть

1. Игроки занимают свои места.
2. Нажимайте на кнопку как можно быстрее.
3. Выигрывает игрок, который наберет 100 быстрее.

## ▶️Запуск
1) Перейдите в папку с игрой и запустите командую строку из этой папки.
2) Запустите server.py (с помощью команды python server.py) на одном из компьютеров.
3) Запустите client (client.exe) на обоих компьютерах.
4) Кликайте!!!!
